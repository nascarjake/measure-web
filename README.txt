MEASURE — WEB EDITION

Serve this folder from a web server; opening index.html directly will not load WebAssembly.
This edition plays bundled Originals plus player-selected MP3, Ogg and WAV files stored only in this browser. Browser music uses a 500 MiB app cache and 100 MiB per-file limit; folders, video sessions, chart-file I/O, and unlimited local-library storage are available in the free desktop apps.
Original tracks use a 96k web encode; desktop packages keep the original audio.
